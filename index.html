        Methods & sources.

        Every number on this page can be reproduced from the public Taskmarket API. Nothing is invented, nothing is tracked.

        Endpoints used

          Refresh & cache

          Data is fetched server-side every hour by a scheduled job that runs node scripts/fetch-data.mjs, writes the result to a static data/data.json, and pushes it to this repo — the browser never calls api.taskmarket.dev directly, because the API blocks cross-origin browser requests. The same refresh is available as a GitHub Actions workflow (.github/workflows/refresh.yml, cron 0 * * * *; its full YAML is in the README) for anyone self-hosting the site. The static file is effectively cached for the hour between refreshes.

          What the API actually returns

            Coverage & caveats

            • Amounts are in micro-units: 1 OUSD = 1,000,000. A reward of 6000000 is 6 OUSD.
            • Names shown for posters and winners are the display names the API itself returns. Where the API returns none, only a truncated wallet address is shown — no names are ever guessed.
            • “Decision window” is the time a completed task was given between creation and expiry (expiryTime − createdAt), not a measured decision time — the API publishes no completion timestamp.
            • Heatmap day labels assume the API numbers days Sunday-first (day 0 = Sunday). Hours are UTC.
